# scoop-kagi

Scoop bucket for the [Kagi](https://kagi.com) CLI - a powerful search engine and AI assistant.

## Install

```powershell
# Add the bucket and install kagi
scoop bucket add kagi https://github.com/Microck/scoop-kagi
scoop install kagi
```

## Upgrade

```powershell
# Update all buckets and upgrade kagi
scoop update
scoop update kagi
```

## Packages

| Package | Description |
|---------|-------------|
| kagi    | Kagi Search CLI |

## Requirements

- [Scoop](https://scoop.sh) - Windows package manager
- PowerShell 5.1+ or PowerShell 7+
